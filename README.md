# PhonePadNX

Телефон как геймпад для Nintendo Switch. Проект временно переведён в режим диагностики.

**Не устанавливай версии 0.1.0 и 0.1.1:** получено сообщение о перезагрузках консоли и проблемах с физическими Joy-Con. Причина пока не установлена.

Если старая версия осталась на SD, выключи консоль и удали только папку `atmosphere/contents/4200000000505044`, затем перезагрузи её. Другие папки в `contents` не трогай.

## Что делает 0.2.0

Проверяет связь с телефоном. Кнопки и положения стиков отображаются на экране Switch.

В сборке нет фонового модуля, автозапуска и виртуального контроллера. В играх она не работает. Это не исправленная версия старого модуля.

1. Скопируй папку `switch` из ZIP на SD.
2. Запусти **PhonePadNX Check** и оставь его открытым.
3. Подключи телефон к той же Wi-Fi сети, отсканируй QR и нажми «Подключиться».
4. Нажимай кнопки: счётчик пакетов и значения на Switch должны меняться.
5. Кнопка `+` на физическом контроллере останавливает сервер и закрывает приложение.

Для удаления достаточно убрать `switch/PhonePadNX-check`.

## Диагностика перезагрузок

Нужен последний отчёт, совпадающий по времени со сбоем. Обычно он находится в `atmosphere/fatal_errors`, `atmosphere/crash_reports` или `atmosphere/fatal_reports`. Для сетевого теста пишется `config/phonepad/diagnostic.log`.

## Сборка

Нужны devkitPro с `switch-dev`, make и Python 3.

```sh
python3 tools/embed.py
make -C launcher -j2
python3 tools/package.py
```

Старая папка `sysmodule` оставлена для расследования. Её сборка заблокирована.
